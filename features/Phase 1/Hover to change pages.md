The page changes the moment you hover another link (with ⌘ held, by default).

> [!use] Using it
> Hover a link anywhere in Obsidian with the hover key held ([[Hold a key to preview]]). Links inside the window itself don't change its page on hover, so reading it never jumps away under the cursor; click one to go there.

> [!how] How it works
> `main.js` takes over Obsidian's hover previews and renders the note into the floating window.
