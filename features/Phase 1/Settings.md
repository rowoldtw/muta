Settings for the window's look, how it behaves, agents and order notes, in Obsidian's settings under Muta.

> [!use] Using it
> **Look:** Liquid Glass, Glass style, Darkness, Mark the previewed note. **Behaviour:** Hold a key to preview, Show on every Space, Swipe to move, Overscroll. **AI (experimental):** Show when an agent is working, Watch agents edit, Agents in linked projects, and a toggle for each agent to watch (Claude Code, Codex, OpenCode, Cursor, Antigravity), which puts Muta's hooks into its settings. **Order:** Order notes. Each group is a card ([[Settings cards]]). Muta's menu in the top bar opens them ([[Top bar]]).
