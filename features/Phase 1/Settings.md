Settings for the window's look, how it behaves, agents and order notes, in Obsidian's settings under Muta.

> [!use] Using it
> **Look:** Liquid Glass, Glass style, Darkness, Mark the previewed note. **Behaviour:** Hold a key to preview, Show on every Space, Swipe to move, Overscroll. **AI:** Show when an agent is working, and which agents to watch (Claude Code, Codex, OpenCode, Antigravity). **Order:** Order notes. Each group is a card ([[Settings cards]]).
